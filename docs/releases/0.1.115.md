# 0.1.115

- 彻底重构会话历史滚动位置记忆与未读提问定位架构，根治跨会话切换间歇性失效与偶发弹回中间的问题：移除所有手写滚轮/按键猜测器与驻留锁锚定时器，直接复用官方 `AutoScroll` 原生离底状态（`overflowAnchor` 与 `.agy-scroll-bottom` 显隐）及 `[data-turn-content="latest"]` 底部对齐判定；在 `history.pushState` / `replaceState` 原生跳转前同步快照活体旧会话锚点并冻结卸载节点，改以 `mountedViewportCid` 同步识别跨会话挂载（消除微任务与 `setTimeout(0)` 竞态冲掉存档，同会话重连重挂载绝不误跳）；恢复时调用官方 `stopAutoScroll()` 配合 1 帧 `rAF` 交由浏览器原生 `overflow-anchor` 无感稳态，并接入官方 `paginationRef.navigateTo` 支持超过首屏 50 步的长会话跨分页恢复，同时结合 `trajectorySlice.totalStepsLength` 水位线精准识别后台新增步骤推进。
