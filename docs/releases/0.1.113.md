# 0.1.113

- 修复右键使用文件菜单后导致「项目」Tab 页对话拖动加入文件夹、侧栏对话右键菜单定位及回车发送状态判定失效的问题：移除文件右键菜单 `#aq-file-ctx-menu` 上的 `role="menu"`（与同级自定义菜单保持一致），并收口 `findActiveNativeMenus()` 排除注入器自有及隐藏菜单节点，避免隐藏 DOM 误判为活跃原生菜单。
- 新增文件外部打开与跨平台编辑器自动识别：动态探测本机已安装的主流代码/文本软件（涵盖 IntelliJ IDEA 项目模式与轻量框 `-e` 模式、VS Code、Cursor、Notepad--、Notepad++、Sublime Text、Zed），并在末尾始终提供系统自带编辑器保底（Windows「记事本 `notepad.exe`」、macOS「文本编辑 `TextEdit`」），未安装的软件自动隐藏；支持在对话文件胶囊、工具卡片、右侧变更文件列表及预览器面包屑上右键呼出动态软件菜单（仅真实支持命令行跳行的软件如 IDEA 项目模式、VS Code、Sublime Text 等显示并执行 `#L行号` 精准跳转，IDEA 轻量框与纯文本软件不误标行号）以及「在访达/资源管理器中显示」「复制路径」；同时在「设置 → 外观」与齿轮「注入器设置」中提供动态下拉框配置「点击文件名默认打开方式」（本机缺失原默认软件时自动回退至「内置预览」，不拦截带审批操作的 Artifact 卡片与目录链接，`Option/Alt + 左键` 可临时走内置预览），并复用本地编辑器探测缓存避免每次点击重复全盘扫描。
- 将侧边栏左上角「新聊天」「定时任务」「自定义」三个纵向入口合并为单行紧凑横条：左侧保留「+ 新聊天」主入口，右侧紧挨「定时任务」「自定义」两个紧凑图标按钮（`26×26px`，悬停展示中文提示、激活态柔和底色高亮，全部一键直达且保留原生路由事件），释放约 63px 侧边栏纵向空间。
- 大幅调淡侧边栏收起文件夹右侧的对话数量提示（浅色 `0.28`、深色 `0.26`），减少常驻视觉干扰；同时在「设置 → 外观」及配额浮层齿轮「注入器设置」弹窗中新增「显示收起文件夹数字」开关，支持持久化记忆与多窗口实时同步。
- 修复侧边栏「分组」视图下右键重命名对话失效及菜单体验不一致问题：「进行中」「最近会话」与自定义文件夹内的所有对话行右键统一优先打开官方完整菜单（保留文件夹归组操作，支持同会话右键重定位、跨会话自动关闭旧菜单防串号），未挂载的归档对话降级菜单同步补齐「重命名」；点击「重命名」后直接在当前可见行原位展开内联输入框，后端保存成功后再落盘同步、失败则无污染一键回滚，同时加强跨实例热重载事件解绑与实例归属校验。
- 彻底修复超长分页对话（如数百步长会话）切换回来时偶发跳回上方旧回复的问题：改用消息步骤节点锚点（`data-step-index`）替代纯像素偏移恢复位置，支持首帧渐进挂载等待、超时末次兜底定位与慢加载超时不覆盖原锚点，以及早期未加载分页安全停底（不再触发顶部自动翻页）；同时仅在实际向上滚动离开底部时才记录手动停留位置，消除在底部下滑滚轮或未读自动定位导致的误锁定。
- 统一本轮明细悬浮卡片字体层级：标题使用 `11px`，输入/输出/累计行等核心账单区统一为 `10px`，缓存命中率、请求明细/思考输出折叠栏及其展开明细与底部汇率说明统一为 `9px`，整体更紧凑且层次分明。
- 为 Token 数量展示新增自适应单位：低于 1,000 显示 `tok`（如 `330 tok`），1,000～99,999 显示 `K`，100,000 及以上保持 `M`，避免思考输出、未缓存输入和正文输出等中小数值统一缩成 `0.00M` 影响辨识。
- 修复切号或一键唤醒重启 Antigravity 后，若窗口仍在初始化阶段即触发探测失败会直接冷却 60 秒的问题：改为识别页面加载状态并采用短重试与阶梯退避策略，同时在切号重启结束（含异常路径）后统一重置旧探测冷却，避免切回后界面未及时注入或单号就绪超时失败。
- 修复自定义拉宽或铺满对话宽度时官方左侧轮次导航小圆点自动隐藏的问题，并保持左右对称的紧凑留白，不浪费左侧横向空间。
