# 0.1.0

- 支持 macOS（arm64 / x64 DMG）与 Windows（x64 NSIS 安装包）独立应用入口，无需本地预装 Node.js，不配置开机自启动。
- 启动器联动拉起或直接附着已打开的 Antigravity 客户端，并在主应用退出后自动退出注入器。
- 支持从 GitHub Releases 自动检查并后台预下载校验更新，点击“立即更新”即可原地替换注入器并重新注入，全程无需重启 Antigravity。
- 提供每轮对话底部 Token 摘要、输入框右下角上下文占用与实时额度胶囊、Codex 风格主题与界面汉化；Windows 上保留账号切换区域并提示暂不支持快照切换。
