# 0.1.25

- 侧栏改为「分组 | 项目」平滑切换双标签页布局，并优化文件夹排序、汉化范围、分隔对齐与右键菜单：
  - **原版纯净中性配色、无外轨纯白页签、纯白卡片分区与输入框淡蓝光晕**：保持原版 Codex 纯白/中性浅灰背景并统一顶部标题栏与侧栏外框底色为 `#fcfcfc`（消除浅灰接缝色差），顶部导航（`新聊天 / 定时任务 / 自定义`）与底部「设置」保持通透无框悬浮行，中间以细横线分隔并采用无外轨「分组 | 项目」滑动白框切换栏，下方「进行中 / 文件夹 / 最近会话」以及「项目」页内的「置顶」与「项目」均采用独立单层同色圆角纯白卡片（`#ffffff`）；对话输入框添加轻细蓝框与向外扩散的淡蓝色柔和光晕（聚焦时微幅增强）；对齐 macOS HIG `13px` 字体比例（`SF Pro Text / PingFang SC`），区分选中态主标题（`500`）与项目目录副标题（`11px`、`400` 字重）。
  - **对称标签切换与分组三区独立分类**：
    - 顶部「分组 | 项目」切换条保持完整对称居中并支持滑块与透明度平滑过渡，消除闪烁。
    - 顶部分区重命名为独立的 **「进行中」** 卡片区（状态圆点，仅在存在运行/待确认/未读任务时显示，空闲时自动隐藏）。
    - 中间文件夹列表移除「文件夹」文字标题、层级竖线、列表中多余的新建按钮行及文件夹内会话的「管理文件夹」图标按钮（仅保留移出分组按钮）；支持**指针直接拖动文件夹进行上下前后排序与嵌套归档**（前移/放入/后移高亮线），并对齐高度调整拖拽条与卡片间距。
    - 最下方提供可折叠、标题固定不挤压的 **「最近会话」**，作为与「进行中」「文件夹」平行的独立分类，**按最后操作时间倒序**展示最近 10 条会话，允许会话在三块分类中同时存在；**在进行中/最近会话上右键弹出与原生「项目」会话完全一致的操作菜单**。
  - **项目会话快捷加文件夹、右键/三点文件夹菜单与建文件夹**：在「项目」与「置顶」页每个原生会话行右侧操作区新增加入/管理文件夹图标按钮，同时在**会话右键菜单与三个点（`⋮`）菜单内直接集成「加入/管理文件夹」子菜单（支持勾选分组与回车新建分组）及快捷「移出文件夹」**；在分组面板空白处或文件夹上右键可新建根文件夹 / 子文件夹、重命名或删除。
  - **长按 / 拖动自动切页与折叠文件夹自动展开**：在「项目」页长按（260ms）或拖动会话时自动切回「分组」页方便归档；拖入折叠文件夹悬停自动展开且放置后保持展开，并校准运行中四点图标居中。
  - **补全对话步骤、右键菜单与悬浮框汉化、5 小时配额加日期**：将桌面端原生右键菜单切换回可汉化的页面浮层右键菜单（完整汉化「重命名 / 置顶 / 标为未读 / 复制 / 分屏打开 / 归档 / 删除」及子菜单）；修复 `[data-testid="agent-response"]` 内卡片按钮（如「审查」「已运行 …」「… 个文件已更改」「… 分钟前」「刚刚」及会话悬浮提示 `更新于 …`）未被汉化的问题；配额悬浮框及账号配额提示中的 `5h` 与周额度重置时间统一附带日期（`月/日 时:分`）。
  - **置顶状态自动恢复**：「进行中」内条目按进入顺序稳定展示不频繁重排；曾从「置顶」移入文件夹并在全部文件夹移出的对话将自动恢复置顶状态。
