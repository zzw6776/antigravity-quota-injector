# 0.1.132

- 优化标题栏右侧简洁模式切换按钮：采用与原生顶栏一致的 `28×28` 圆形 + `18×18` 侧栏展开/收起箭头图标，并补齐自绘即时悬浮提示；点击不再触发新弹窗，而是直接将当前窗口在「简洁模式（隐藏左侧边栏）」与「完整界面（显示左侧边栏）」之间原地切换（主窗口与独立窗口行为统一）。
- 修复 Windows 平台独立聊天窗前置因 PowerShell 参数传递方式错误导致失效与潜在命令注入的问题，改为 `-EncodedCommand` 搭配环境变量传参，并补齐非前台窗口加权与截断标题前缀匹配。
- 修复独立聊天窗标题尚未就绪（`Antigravity`）时可能误抬其他后台窗口的问题。
- 修复独立聊天窗整页重载瞬间守护进程误清除独立窗标记导致单击前置短暂失效的问题。
- 优化独立聊天窗交互与性能：双击已开独立窗会话不再并发触发多次置顶调用（后端同步做在途去重），拆出新窗等待阶段仅精准附着新窗口而非高频扫描全部已有窗口。
