# 0.1.63

- 新增账号批量「一键唤醒」功能：在配额浮窗「账号切换」栏的 `+ 登录新号` 左侧新增带二次确认的白灰胶囊风格「一键唤醒」按钮，重启前自动过滤无订阅及未在 `keepalive.json` 中打开任何唤醒开关的账号；切号后以实时配额为准唤醒所有已开启的模型池并回写快照，完成后切回起始账号；运行中可随时停止并停留在当前账号，右下角独立浮动进度面板实时展示进度。
- 修复开发版跨重启切换时的守护进程分离与 `SIGHUP` 退出问题：启动 Antigravity 时清理 `AQ_DETACHED_CHILD` 等内部握手环境变量，并忽略宿主机重启/关闭终端触发的 `SIGHUP`，同时在页面等待阶段增加 1.5s 短周期就绪重试，确保批量切号稳定接续。
- 在「账号切换」列表保留左侧原有圆点颜色的同时，为重置时间已到或满额可用但新一轮刷新倒计时尚未开始的账号在额度摘要旁新增独立琥珀色小圆点提示；并修复极轻度消耗（仍显示 `100%`）的 5h 池倒计时判定，确保优先显示 5 小时倒计时而非回落到周倒计时。
- 优化整体浮窗与外层芯片 UI：倒计时全局统一为紧凑 `d/h/m` 格式（如 `2h57m`、`6d04h`），模型池明细采用等宽倒计时四列网格严格垂直对齐；统一浮窗内健康绿色为清透翡翠绿（`#059669` / 暗色 `#34d399`），外层芯片、上下文悬浮框及配额浮窗顶部的正常态采用与宿主一致的常规字体与字色（仅低额度或高占用时亮警示色），上下文悬浮框去除冗余前缀标签并居中对齐；微调浮窗内次级字号、标题左对齐及模型组圆点视觉重心。
- 优化对话运行中单轮统计条位置：生成期间存在 `Working` 指示器时，确保最新一轮「本轮耗时…」始终置于 `Working` 下方，待本轮结束且工具栏挂载后自动收回到正文与工具栏之间。
