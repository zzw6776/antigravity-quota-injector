# 0.1.58

- 全面优化前端渲染与后端同步性能：取消全局 `requestAnimationFrame` 源码扫描拦截并改为细粒度按需标脏，消除空闲状态每 2 秒的全页面汉化、轮次重算与强制重排；为高频滚动、拖拽与底栏变化加入合批/节流，缓存数字格式器并改用 `WeakMap` 管理汉化节点缓存，补齐热重载实例清理。
- 全面优化守护进程数据管线与内存管理：对已完结历史对话轮次启用 SQLite/Protobuf/费用增量缓存及尾部增量下发，移除无用的 CDP `Runtime.enable`/`Page.enable` 事件洪泛，为非目标页面增加探测冷却并改为多窗口并发同步，避免单窗口重复读盘与日志无上限增长，并优化 Windows 安装包 PE 头流式校验。
- 修复 Antigravity 重启或切换账号更换本地端口后会话宽度失效并自动回落为全宽的问题：改为由注入器守护进程统一在 `ui-prefs.json` 中持久化保存与多窗口同步会话宽度设置，并兼容迁移当前本地缓存；未主动设置时保持默认 `768px` 居中宽度而非强行铺满。
