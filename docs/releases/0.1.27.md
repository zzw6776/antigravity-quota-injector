# 0.1.27

- 微调对话输入框外围蓝色轮廓与阴影质感：适当加重细蓝描边对比度并小幅扩大淡蓝色外扩阴影范围（同时适配浅色与深色模式）。
- 修复侧栏「项目」页签顶部「置顶」卡片左上与右上圆角缺角问题：仅为实际发生滚动的粘性分组头启用卡片遮罩背景，并为粘性分组头裁剪路径与圆角匹配卡片内侧 9px 弧度。
- 优化「进行中」状态即时响应：发出消息（回车或点击发送）及输入框处于发送/取消态时立即归入「进行中」（兼容新建对话与切走会话场景），无需等到模型真正开始输出且不阻塞 10 秒轮询；无进行中任务时保持卡片常驻且不再展示「暂无进行中会话」占位文案。
- 简化非当前账号配额浮层展示：配额已到重置时间且原本满额时仅显示「已重置」，去掉冗余的「· 预计满额」后缀。
- 精简侧栏「分组」页签折叠指示：移除「进行中」、自定义文件夹与「最近会话」上的多余箭头，文件夹改用开/合两种文件夹图标区分展开与收起态，收起后不显示数字角标。
- 修正账号列表 Gemini 额度可用性判定：用完额度后残留 1%（显示为 1%，`remainingFraction < 0.015`）时按已用完（红点）处理，避免误标为绿色可用。
- 新增启动时自动重启未开启注入的 Antigravity：打开注入器时若检测到 Antigravity 已在运行但未开启远程调试端口（无法注入，包括存在失效 `DevToolsActivePort` 残留的情况），自动优雅关闭并带 `--remote-debugging-port=0` 重启 Antigravity 完成注入（支持 macOS 与 Windows）。
