# 0.1.24

- 优化侧边栏「分组」高度调节模式为「自由拖动设定上限 + 松手自动回弹贴合内容」：
  - 拖动底部分隔横线时可自由向下超越当前内容长度（实时显示「上限 XXXpx」悬浮气泡），不受内容少而卡住；
  - 松手后自动记忆该最大高度上限 `max-height`：若当前内容较短，分隔线会以 `180ms` 平滑动画回弹贴合内容底部（绝不留空白），后续展开文件夹或新增对话时才会撑满到设定的上限高度；双击横线恢复默认 `clamp(180px, 40vh, 380px)` 上限。
- 优化「未确认 / 运行中」分组移进移出动画与防闪烁机制：
  - 将分组面板拆分为「静态骨架」与「增量原地更新」，切换对话、状态变化或智能分组进出/折叠不再重建整个 `panel.innerHTML`，彻底消除四点呼吸动效重启、悬停态丢失与滚动位置回弹闪烁。
  - 为「未确认 / 运行中」列表启用 keyed 节点复用与 `200ms` 平滑高度展开/收起及淡入淡出过渡，并新增 `1.2s` 移出宽限期与本地已读时间戳防回滚，过滤工具调用间隙或后端同步延迟导致的反复进出闪动（主动点开未读对话仍立即平滑移出）。
- 在侧边栏「分组」顶部新增常驻动态分组「未确认 / 运行中」：将等待审批/回复（琥珀色脉动圆点）、执行完未读（同心圆点）与正在运行/后台任务中（四点呼吸动效）的全部侧边栏主会话合并汇总在同一个分组内，并按「等待确认 > 未读 > 运行中」及最新更新时间排序（自动过滤已归档及子代理，并将子代理状态冒泡至父对话）；无对话时常驻显示数量 `0`，支持折叠持久化、点击直达及一键归入自定义文件夹，同时在自定义文件夹中同步支持「等待确认」状态指示。
- 在账号列表每行左侧新增柔和的 Gemini 额度可用状态小圆点（5px 低饱和半透明点，无外圈光晕）：柔绿表示 Gemini 额度可用（含已跨过重置时间预计恢复可用），柔红表示 Gemini 的 `5h` 或周额度已耗尽且尚未重置，淡灰表示尚无本地配额记录，不突兀且一眼可辨。
- 支持不切换账号查看其他已保存账号的本地额度快照：自动记录当前账号的各模型分组配额与重置时间，并在切换账号或登录新号前自动保存；在配额面板的账号列表中将鼠标悬停在任意账号行上，侧边会弹出悬浮卡片展示该账号的 `5h / 周` 剩余额度与重置倒计时，若已跨过上次记录的重置时间则自动标为「已重置」。
- 统一配额悬浮框点击刷新交互：取消悬停自动刷新及再次点击徽章收起悬浮框的切换逻辑，点击配额百分比徽章、上下文占用徽章或悬浮框非按钮区域均保持悬浮框展开并立即强制刷新配额（顶部实时展示「刷新中…」提示），点击外部区域或按 `Esc` 关闭。
- 为自定义文件夹内的对话补充原生风格的「未读」（同心圆点）与「正在运行」（四点呼吸动效）状态指示：实时同步侧边栏原生状态，并结合后台会话列表定期刷新视口外及折叠项目中的对话状态，悬停时自动切换为操作按钮。
- 修复鼠标悬停在侧边栏文件夹标题或单行对话项上时列表发生上下抖动的问题：锁定文件夹标题高度为 `28px` 并为文件夹对话项设置 `32px` 最小高度，消除悬停操作按钮显现时的高度变化。
- 优化模型配额实时刷新节奏：调用 `RetrieveUserQuotaSummary` 启用 `forceRefresh: true` 击穿 `language_server` 内存缓存，并依据每轮 `completed` 状态分层节流——长任务进行中最多每 30 秒顺带同步 1 次、本轮回答结束经 1.5 秒尾随防抖必刷 1 次（最小 10 秒冷却并自动延后补刷），空闲态每 120 秒或跨过重置点兜底同步，兼顾实时性与低请求频次。
- 精简侧边栏对话右侧悬停操作栏：移除注入的「加入分组」按钮并隐藏原生「归档」「停止执行」按钮，仅保留「置顶/取消置顶」与「更多（三个点）」，保持列表整洁（侧边栏对话仍支持直接拖入顶部文件夹）。
- 优化配额重置时间展示格式：将悬浮卡片中的「X小时Y分后重置」改为「倒计时 + 本地目标时间」组合展示（如当天显示 `4小时19分 (20:55)`，跨天自动附加日期如 `2天2小时 (11/21 12:05)`）。
- 在侧边栏「自定义」与「分组」区块之间补充与下方一致的顶部分隔横线，保持视觉分区对称清晰。
- 修复自定义分组内对话选中态无法取消及顶部间距过宽的问题：优先依据主视图 `[data-testid="conversation-view"]` 与侧边栏原生选中态同步当前对话 ID（不再被过期 `location.pathname` 卡住），点击分组内对话优先复用原生侧边栏链接跳转，并监听 `data-selected` / `data-cascade-id` 变化实时刷新选中态；同时收紧「自定义」与「分组」区块之间的顶部间距。
- 精简侧边栏文件夹标题栏操作按钮：移除分组标题栏右侧的 `+`（加入当前对话）按钮，仅保留「新建子分组」「重命名」「删除」，减少误触并保持界面清爽。
- 对话归入自定义文件夹后自动取消「置顶」：将已置顶的对话拖入或加入任意文件夹（含子分组）并确认归组成功后，自动调用原生取消置顶，避免同一对话同时在「分组」与「置顶」区域重复展示；后续仍可随时手动重新置顶。
- 适配 Antigravity `2.33.0+` 远程调试端口默认关闭变更：通过注入器启动或切换账号重启 Antigravity 时自动传入 `--remote-debugging-port=0` 开启 CDP 注入能力；当检测到 Antigravity 已在运行但未开启远程调试端口时，在日志中给出明确排查提示。
- 提升账号切换与新账号登录自动重启可靠性：在退出 Antigravity 并写入凭据后若首次拉起未检测到进程启动，自动执行一次延迟重试并记录完整操作日志。
- 新增侧边栏自定义对话分组与多级嵌套子分组功能（最多支持 4 级）：支持在任意分组内新建子分组、树形层级展示与数量汇总、归组菜单树形缩进选择、将侧边栏对话直接拖入任意层级子分组（悬停折叠文件夹自动展开）、在不同分组间拖动迁移对话，以及拖动文件夹调整顺序、拖入另一文件夹成为子分组或拖回顶层。
- 新增每轮对话与会话累计人民币价格估算：支持 `Gemini 4 Neon`（含 `Orchestrator (Neon)`）、`Gemini 4 Carbon / Argon / Hydrogen`、`Gemini 3.8 / 3.7 / 3.6 / 3.5 Flash`、`Gemini 3.1 Pro`、`Claude Opus / Sonnet 5.5 & 4.6` 及 `GPT-OSS 120B` 官方标准 API 费率，自动拉取并缓存国家外汇管理局美元兑人民币汇率中间价，在底部统计栏展示本轮价格、在悬浮卡片展示输入/缓存/输出/思考分项单价与累计费用。
- 优化每轮对话底部 Token 统计栏交互样式：取消鼠标悬停变深色效果，并将悬停光标调整为文本选择光标（`cursor: text`）。
- 修复账号订阅等级判断不准的问题：优先根据 `GetUserStatus` 中的 `userTier` 识别真实订阅，准确区分 `Ultra 5x`（`g1-ultra-lite-tier`）、`Ultra 20x`（`g1-ultra-tier`）、`Pro` 与 `Free`，不再被兼容字段 `planStatus.planInfo.planName` 固定覆盖为 `Pro`，并在订阅变化时自动同步更新账号快照。
