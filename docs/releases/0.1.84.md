# 0.1.84

- 支持文件夹与会话自由拖动排序、收起态显示会话数量及新拖入项置底：同文件夹内的子文件夹与会话现支持相互上下拖动混排调整顺序（不再硬性将所有子文件夹锁在会话上方，并保证多层嵌套移动后弹窗菜单目录顺序同步一致），外层根文件夹与子层级均支持松手即时落位排序；当文件夹处于收起状态时在右侧显示其内部包含的会话总数（展开时自动隐藏）；从外部列表或跨文件夹新拖入、加入及新建的项统一排在目标文件夹最下方，并统一拖拽期间的半透明态、屏蔽沿途行悬停按钮闪烁与保持自动展开后的落点高亮。
- 修复「本轮耗时」在等待子代理或一次性后台命令返回期间卡住不动的问题，并将耗时统一为整数秒显示：自本轮起点（`startTsMs`）起按秒实时递增刷新（小于 1 分钟统一显示整数 `X秒` 不带小数点，`首字` 保持小数秒显示），直至主线程空闲、挂接的子代理全部结束且 `ListBackgroundTasks` 中无待返回的一次性后台任务（自动排除 `isDaemon: true` 的常驻开发服务/守护进程及用户独立终端）时才停表定格；同时隔离已挂出完结操作栏的历史轮次避免追问发送瞬间上一轮耗时闪跳，补齐 SQLite 步骤运行态（`status = 2/4`）与子代理回调步骤（`step_type = 101`）的时间边界识别，并按轮次保存确认耗时峰值，确保停表、中途手动停止子代理及后续追问新轮次时平滑定格不倒退。
- 调整侧边栏「最近会话」排序规则：改为严格按用户最后发送消息的时间（`lastUserInputTime`）倒序排列，不再受后台 AI 持续输出、工具调用或浏览切换带来的 `lastModifiedTime` 更新干扰导致列表顺序来回跳动；用户在输入框发送或排队追加新消息时立即置顶并稳定保持至服务端落盘。
- 新增运行中「查看实时思维链」无框纯图标按钮与自动刷新卡片：仅在当前轮次运行期间（含等待子代理或一次性后台任务返回阶段），于原生思考/运行状态行右侧精确对齐文字视觉中线挂载无边框星芒图标，展开/悬浮均保持纯图标无外框样式；点击展开实时思维链中文卡片并按单一节拍自动同步最新思考（通过祖先链归属去重精准提取单轮多段工具调用后的后续流式思考步骤，避免旧折叠块覆盖新思考或重复计数），再次点击星芒图标（或卡片右上角 `×`）即刻缩回卡片并释放离屏节点与文本内存，会话运行态与视口挂载态正交解耦确保长对话滚动时不误关卡片、不误挂历史轮次，轮次结束后自动隐藏清理；同时自动合并多余空行并以紧凑段落展示，支持「看原文 / 看译文（看简述）」零延迟瞬时切换，「看原文」展开期间仅轻量同步本地最新原文而不触发外部翻译调用。
- 原生内置全套五渠道直连翻译与「AI 简述」（零外部依赖、彻底移除本机 Easydict 服务依赖）：使用 Node.js 原生 `fetch` 与 `crypto` 直接集成 `Google 翻译`、`DeepL 翻译`（自动识别源语言并同步移动端版本号）、`Bing 翻译`（自动刷新网页令牌与长文本分段）、`有道翻译`（动态密钥与 AES-128-CBC 解密）以及智谱 `glm-4-flash-250414` / OpenAI 兼容大模型接口驱动的 `AI 简述` 与 `AI 翻译`（对智谱 4.5+ 与硅基 Qwen3 混合推理模型自动关闭内部慢思考以避免超时）；无需安装或开启 Easydict 本地端口，macOS 与 Windows 双端开箱通用，支持旧渠道偏好值自动平滑迁移、密钥摘要纳入缓存指纹、多级渠道自动降级回退及自定义简述提示词（`aiBriefPrompt`）。
- 配额面板版本号同行左侧新增纯图标设置入口与本地 AI Key 配置弹窗：在配额浮层底栏版本号左侧提供简洁纯齿轮图标入口，点击弹窗直接在输入框中明文展示与编辑本地 `config.json` 中的大模型 API Key、模型名称与可选接口地址（严格隔离环境变量密钥避免误落盘，内置写入异常反馈与超时恢复）；密钥仅以 `600` 权限原子保存在本机用户目录 `~/.gemini/antigravity/quota-injector/config.json` 中（绝不写入代码仓库），修改或清空保存后即时刷新各窗口缓存并热生效。
- 优化 `verify` 校验命令页面识别：存在本地开发预览页（`localhost` / `127.0.0.1`）同开时，优先定位真正的 Antigravity 宿主窗口执行校验。
