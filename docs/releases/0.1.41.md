# 0.1.41

- 全面优化前后端高频路径性能：前端 `MutationObserver` 改为按职责域脏标记（`chip / sidebar / turns / menus / i18n`）分流调度，自动忽略输入框打字与 Markdown 流式生成正文节点变动，阻断 AI 流式输出期间每帧触发侧栏全量采集与全页翻译扫描；为界面汉化文本节点、属性及控件增加节点级幂等缓存，并对侧栏 React Fiber 项目索引与已分组会话集合做 `O(1)` 缓存以消除 `getBoundingClientRect()` 强制同步布局重排；Node 守护进程侧将 SQLite `steps` 查询优化为按 `step_type` 条件投影 `metadata / step_payload` BLOB 字段，并对 `buildClientScript` 按配置与资源文件 `mtime` 缓存，消除长会话无效大字段内存拷贝与每 `1.5s` 轮询重复读盘哈希。
- 优化侧栏无项目会话第二行展示并补全跨标签页项目归属提取：无项目（独立对话）会话在「分组」页三区与「项目」页混合列表中统一于第二行展示对话气泡图标配减淡灰「无项目」副标题，使所有会话主标题基线严格对齐且一眼区分独立对话与项目目录；同时通过原生侧栏虚拟列表项与项目组头标识直接解析会话所属项目，修复处于「分组」页时部分未置顶项目会话漏显示目录名的问题。
- 新增主会话与输入框宽度自适应铺满及底部输入对话框左右边缘拖拽调节：默认解除 `48rem`（768px）最大宽度限制，并将宽度拖拽触发热区严格限制在底部输入对话框（`#antigravity.agentSidePanelInputBox`）的左右两侧竖边（鼠标在输入框左右边缘放置满 `0.3s` 后唤醒贯穿整个主会话页面高度的左右双侧淡蓝参考竖线与拖拽光标，上方对话流区域日常移动与点击互不干扰；原地点击未发生位移时保持唤醒态以确保双击切换正常触发），拖动期间采用 `requestAnimationFrame` 帧同步与目标容器非继承 `max-width` 直写（单帧耗时由 `27.5ms` 降至 `0.76ms`）同步缩放主会话流与输入框宽度；支持拉到接近边缘自动吸附为「自适应 100% 铺满」、靠近 768px 默认宽度微吸附、双击固定在「官方默认 `768px` ⇄ 自适应 `100%` 铺满」间一键切换，以及本地持久化记忆。
- 修复热重载残留多实例互抢侧栏 DOM 与高开销样式选择器导致的页面严重卡顿：新增实例清理注册表与 `requestAnimationFrame` 旧实例拦截保护，优先断开观察器与定时器并对各子模块清理独立兜底，彻底阻断分步编辑热注入时残留僵尸实例引发的每帧死循环重建；同时将侧栏会话行的 `:not(.text-muted-foreground *)` 与 `:has()` 选择器优化为直接子代选择器，并对主会话宽度 CSS 变量与拖拽热区位置写入做变更判重。
- 统一侧栏会话行双行高度（42px）：无论会话是否关联工作区文件夹，在「分组」页全部三区（「进行中」、自定义分组及子分组、「最近会话」）以及「项目」页的「置顶」、平铺模式、按状态/位置分组、自定义分组与独立会话区块中均固定为统一的 42px 高度，同时保留「项目」页按项目目录树展开后的缩进子会话为紧凑单行，并修复原生会话行目录副标题字号被放大为 13px 及选中加粗的问题。
- 新增 Windows 账号快照与一键切换支持：通过 Windows 系统凭据管理器（`Advapi32.dll` `CredReadW` / `CredWriteW` / `CredDeleteW` 操作 `gemini:antigravity` 通用凭据）配合 `%APPDATA%\Antigravity` 下的 `credential-user-scope` 与 `app_storage.json`（兼容 `agy.onboarding.*` 与 `jetski.onboarding.*` 登录标识）实现与 macOS 一致的账号自动/手动快照、新账号登录引导及一键切换重启。
- 修复 Windows 客户端侧栏「分组 | 项目」双标签页、分组三区卡片（「进行中 / 文件夹 / 最近会话」）与项目纯白圆角卡片未生效的问题：Windows 窗口顶部内嵌菜单栏 `[data-testid="title-menu-bar"]` 同样带有 `.bg-sidebar` 类名且在 DOM 中位于左侧栏之前，导致原先 `document.querySelector('.bg-sidebar')` 命中顶部菜单栏而非左侧会话侧栏；现统一通过 `findSidebarRoot()` 定位包含会话列表/导航项的真实左侧栏容器，并补充 Windows 顶部菜单栏 `View / Window` 汉化与 `Microsoft YaHei UI` 中文字体回退。
- 修复 Windows 正式版自动更新卡在「正在原地替换注入器并重新注入…」的问题：改为通过 GUI 宿主 `wscript.exe`（配合 UTF-16LE `-EncodedCommand` 与独立工作目录）分离拉起后台隐藏 PowerShell 更新脚本，避免 `powershell.exe` 在 Node.js `DETACHED_PROCESS`（无控制台句柄）模式下直接空跑退出导致旧进程退出后未执行安装包与重拉起。
