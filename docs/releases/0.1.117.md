# 0.1.117

- 修复在已展开多页历史步骤的长会话中发送多行消息后，官方 `AutoScroll` 垫片钩子在分页回收收缩时锁死内联 `minHeight`、导致会话底部残留大面积空白的问题，并在视口滚动事件当帧即刻自愈复位，消除短暂空白闪现。
- 修复在内置代码预览、Diff 对比视图及选中文本区域右键时被文件外部打开菜单误拦截的问题，同时修正文件路径面包屑中父级目录节点的类型识别，避免对文件夹展示仅支持单文件的编辑器选项。
- 修复跨会话切入加载骨架屏尚未挂载视口时立即切回原会话导致历史滚动位置未恢复的问题，并将滚动过程中的状态记录改为静止防抖采集，消除滚动热路径的同步布局计算开销。
