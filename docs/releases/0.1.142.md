# 0.1.142

- 支持独立聊天窗**自动记忆并还原窗口大小与位置**（支持多屏负坐标与断开外接屏边界保护）：
  - 平时拖动/缩放独立窗口会自动持久化其坐标与宽高（按会话 ID 保留最近 48 条记录）；再次拆出同一会话时精确还原到上次位置与大小，拆出新会话时自动沿用最近独立窗尺寸；
  - 切换账号（及批量一键唤醒）重启自动恢复独立窗口时，同步把每个已打开的独立窗口还原回原来的屏幕位置与大小（macOS 通过 `AXPosition → AXSize → AXPosition` 精准跨屏归位，Windows 通过 Win32 `SetWindowPos` 还原，未命中目标窗口时安全跳过避免误移动主窗口）。
- 优化输入框底栏配额显示（`#aq-quota-chip`）样式，并新增 **5 套配额百分比配色方案**（原生暖金、macOS 语义、板岩玫红、莫兰迪雾感、极简灰阶，均适配亮/暗双主题）：
  - 改为与原生 `Turbo` 一致的无常驻边框紧凑样式（仅悬停显示浅灰胶囊底），移除 `tabular-nums` 等宽拉宽感，采用 `12px / 500` 字重与柔和中点 `·` 分隔；
  - 已完整整合进「注入器设置」弹窗与 Antigravity 原生「设置 → 外观」面板，支持带亮/暗自适应三色圆点预览的一键实时切换，并通过守护进程持久化同步至所有已打开窗口；同时移除「注入器设置」弹窗背景模糊遮罩，切换配色时可直接清晰预览底栏变化。
- 重设计账号切换列表状态呈现（语义分色）：左侧状态圆点与底栏逻辑统一为绿（充足）/ 橙（偏低 `10%~24%`）/ 红（告急 `<10%` 或已耗尽）三档；下方配额摘要改为按桶独立着色（仅偏低/告急数字着橙或红，其余数字与恢复倒计时保持清爽中性灰），未开始倒计时在保留时间显示的同时于右侧展示「待激活」微标签。
- 修复 macOS 在另一屏幕全屏（跨 Space 桌面）状态下点击已独立打开的会话无法切回目标桌面、误在当前窗口切换会话的问题：在 `AXWindows` 未找到目标窗口、目标处于全屏或 `AXRaise` 未能跨 Space 夺焦时，自动通过应用原生 `Window` 菜单项触发 `AXPress` 交由 macOS 原生切换桌面并聚焦对应窗口。
