# 0.1.50

- 账号切换列表支持拖动排序与下次可用 Gemini 额度倒计时：支持在配额浮层的「账号切换」列表中直接上下拖拽调整账号顺序并持久化保存；每个账号条目下方直观展示下次可用 Gemini 额度的倒计时（耗尽时显示距离下次恢复可用的倒计时与重置时间，可用时显示当前 Gemini 额度及重置倒计时）。
- 优化侧栏「进行中」智能分组留存体验：已位于「进行中」列表的对话在用户停留于当前页面时（无论是刚点开未读消息还是当前会话刚运行结束）不再立刻跳走消失，仅清除未读/运行徽章并稳定保留在列表原位，待切换离开该页面后再平滑移出。
- 优化配额详情浮层与账号切换 UI：采用净白/深炭极简排印（无进度条、无内部滚动条、各模型分组间采用细腻点线分隔、取消当前组选中框仅保留前置蓝点），恢复柔和的绿/黄/红额度百分比与上下文语义色；「唤醒」文字保持纯中性灰不上色、滑块采用与全局一致的蓝色强调轨道；下半部分回归一体化「账号切换」列表，精修当前号淡蓝底、淡灰订阅文字、清透蓝「当前」/细描边「切换」操作位及悬停显露的无框移除图标。
- 修复配额详情浮层「唤醒」开关状态跳变与点击无故重绘问题：守护进程初连与重连时直接从本地登录记录对齐活跃邮箱，前端拦截默认空桶覆盖并改为原地无重绘切换滑块与二次确认按钮，同时移除点击浮层空白区域触发强刷重绘的逻辑。
- 修复单轮 Token 消耗统计栏在任务执行中可能排在 `Working` 状态提示上方的问题，确保始终固定显示在对话轮次最底部。
- 修复配额静默唤醒在首次打开客户端、切换账号或热重载时的异步状态时序缺口，并将唤醒冷却调整为 5 分钟；完善静默唤醒异常与超时判定及多窗口租约锁保护。
- 收紧自动重启客户端的安全边界：Windows 下移除超时强制结束进程树（`/T /F`）兜底以避免丢失未保存内容，命令行参数查询超时或未知时保守跳过自动重启，并对单实例复用请求增加单飞互斥保护；修复 Windows 自更新路径在跨平台单测下的写入目录问题；输入框回车乐观标记「进行中」时排除提及与下拉菜单展开场景。
