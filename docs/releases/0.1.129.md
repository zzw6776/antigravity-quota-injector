# 0.1.129

- 新增「独立聊天窗打开」功能：支持**双击侧边栏任意会话**（原生列表与自定义分组均支持），或在会话标题栏右侧、原生会话右键菜单、自定义分组右键菜单点击入口，将指定会话在独立窗口中打开；独立窗口自动隐藏左侧边栏与左上角悬浮导航按钮，macOS 默认以纯 CSS 稳定留出红绿灯安全间距（并自动兼容左右分屏），随时可点击顶栏「完整界面」一键还原。
- 独立聊天窗启动提速与体验完善：
  - 优先通过 React 根容器获取官方原生 TanStack Router 实例直接无刷新瞬切到目标会话（同时加速自定义分组旧会话跳转），避免二次整页重载；
  - 新窗口附着时抢先下发微型内联样式与路由跳转，并将 10 个 CDP 绑定与水合推送改为并发执行、缩短捕获轮询至 `60ms`；
  - **单击前置与防重复开窗（原生 AXRaise + 自动唤起权限）**：守护进程实时同步活跃独立窗口会话列表，单击已开独立窗会话时通过系统原生窗口 API（macOS 直接调用 `ApplicationServices` `AXUIElement` `AXRaise`+`AXMain`，无需 `System Events` 自动化权限并支持截断标题前缀匹配；Windows 调用 Win32 `SetForegroundWindow`）将对应独立窗直接抬升到最前；若 macOS 尚未授予辅助功能权限，直接通过 `AXIsProcessTrustedWithOptions` 唤起系统授权弹窗并打开「系统设置 → 辅助功能」，同时自动回退在本窗口正常打开不吞点击；
  - 支持**切账号自动恢复独立窗口**：通过插件切换账号（及批量一键唤醒结束切回原账号）重启客户端前自动记录全部已打开的独立聊天窗会话，重启进入主界面后按序自动重开恢复。
- 支持 **macOS 固定自签名证书打包与发布校验**：CI 打包使用固定自签名代码签名证书（`Mac Development: Antigravity Quota Injector Self-Signed`），使 `.app` 的 `designated requirement` 锚定在 `Bundle ID + 固定证书根指纹` 而非易变 `cdhash`，正式版自动更新后可持久保留 macOS 辅助功能权限无需反复重新授权。
- 独立聊天窗采用零权限优先触发与防重入队列协调：优先通过 CDP 原生快捷键拉起新窗口，并通过新 target 快照检测延长冷启动等待上限避免误报或重复弹窗；若未拉起则无打扰降级为快捷键引导提示（`⌘⇧N` / `Ctrl+Shift+N`），并支持 FIFO 队列按序接管与短时双击去重。
- 修复独立聊天窗（及整页重载后的多窗口）因 `window.__APP_CONFIG__.csrfToken` 为空导致配额与元信息接口报 `HTTP 401` 的问题：统一改为优先读取 `__APP_CONFIG__.csrfToken` 并回退读取官方共享的 `localStorage['agy_session_csrf_token']`，同时在冷启动瞬态 `401` 时自动等待认证就绪后补拉一次配额。
- 改进开发版启动器的运行态哈希识别，改为自动扫描 `src/*.mjs` 与 `src/app-update/*.mjs`，避免新增后端模块遗漏热接管检测。
- 修复会话中宽 Markdown 表格触发官方 `.md-table-bleed` 默认外溢样式、突破自定义会话左右宽度边界线甚至贴近左侧轮次导航圆点的问题：默认将表格约束在会话正文列宽内横向滚动，同时保留表格右上角菜单手动「最大化宽度」能力并预留左侧导航圆点间距。
